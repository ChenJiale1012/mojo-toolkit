# Mojo Brand Toolkit

Standalone, private-by-default toolkit built with Vite and vanilla JavaScript. No backend or account system is required. No public deployment has been performed.

## Develop

Use Node 22.12+ (tested with Node 24.19.0).

```sh
cd /workspace/mojo-toolkit
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

Local address: `http://localhost:5173`. Section links use hashes, e.g. `/#colour`; all sections remain directly addressable on static hosting. The existing checkout is isolated; do not create a worktree unless requested.

```sh
npm run build
npm test                  # run with the dev server active
npm run preview -- --port 4173
TEST_URL=http://localhost:4173 npm test
```

Tests use installed `/usr/bin/chromium`. Set `CHROMIUM_PATH` to an alternative executable. They check all chapters, global search, asset filters, clipboard, editable specimen, concept action, actual downloads/ZIP, fonts, images, mobile overflow, mobile navigation, reduced motion, and console errors. Screenshots are saved to ignored `.playwright/`.

## Edit and maintain

- **Guidance, approvals, metadata:** edit `src/content.js`. `chapters` contains descriptions and guidance; `assets` contains real file paths, actual formats, version, use, and approval state. `meta` holds toolkit version and date. Unavailable files have `path: null`. Never mark draft guidance approved without brand-owner approval.
- **Design:** core and functional tokens are in `src/style.css`; approved palette values are also represented in the content source for copy controls and computed contrast. Update both only with approval. Inter is locally bundled; no external font requests occur.
- **Typography:** supplied Mojo Pixel Serif Draft v0.200 is used for main headings and the specimen; Mojo Serif Refined v0.601 for subtitles; supplied Inter v4.001 variable regular/italic for body and controls. Files live in `public/fonts/` and are loaded through `@font-face`. Georgia and Arial are fallbacks only. Record versions in `src/content.js`. Supplied custom TTF files are now downloadable as explicitly requested. Custom licence/readme source files have not been supplied.
- **Mascot and identity:** place the original `mojo-cat-transparent.svg` and other approved files under `public/brand/`. Change unavailable catalogue entries to their real paths and verified formats/versions. Render the original SVG using an image element, without editing geometry, colours, or highlights. The reusable signature in `src/brand.js` places the original cat left of lowercase “mojo” in Mojo Pixel Serif Draft v0.200 (explicit CSS family `Mojo Draft Logo`); this follows the supplied direction, without claiming a separate approved wordmark file. The supplied original mascot is displayed as an unchanged image overlay in the courtyard hero, in the overview shortcut, on four background previews, and in the asset catalogue. The SVG is byte-for-byte identical to the upload. Wordmark, combined logo, and app icon remain pending.
- **Templates:** editable resources are generated by `scripts/resources.py`. Change layout source there, run `python3 scripts/resources.py`, update metadata, then rebuild. SVG files are real vector sources. HTML slides include five layouts and print support; they are not PowerPoint. The supplied Inter variable regular and italic fonts and SIL OFL are included. SVG sources use portable system font fallbacks; HTML pages use the site fonts when served, and fall back when extracted without font files. Do not package font files lacking distribution permission.
- **Resources/pack:** the generator creates `public/downloads/mojo-starter-pack.zip` from existing files only. After changing any generated resource, rerun the generator and inspect the ZIP. Update its README, version and changelog together. Do not include internal or confidential resources: this static website has no access controls.
- **New version:** update `meta`, asset versions, generator metadata and changelog; regenerate resources; run build and browser checks; obtain approval for changes to brand rules before marking them approved.
- **Deployment:** `dist/` is ready for a static host at the domain root. Use `npm run build`, deploy only the `dist/` directory after explicit authorization. No public publishing is part of this delivery.

## Overview refinement (v0.3)

`public/courtyard.png` is original AI-generated environmental concept artwork, created for this project from the requested palette and courtyard direction. It does not reuse the Cofounder illustration. Generated colours use illustrative shades; core UI colours remain exact tokens. The mascot is always composited separately using the untouched supplied SVG. The old desk asset remains downloadable for compatibility.

`src/brand.js` is the shared signature; `src/intro.js` controls the introduction. It types in Mojo Draft Logo after font/mascot readiness, reveals the mascot, and exits in approximately 1.4 seconds, with an absolute 1.8-second watchdog. A sessionStorage flag prevents replay across reloads and routes in one browser session. Skip, Escape, Tab, reduced-motion changes, font/mascot failure and page exit remove the overlay; no focus capture or scroll lock is used. Clear `mojo-brand-intro-seen` from sessionStorage or open a fresh browser session to review the intro again. Storage restrictions cannot block the site.

`npm test` also runs `tests/intro.mjs` for fresh playback, reload/navigation suppression, skip, keyboard access, reduced motion, failed fonts/images, unavailable storage and scroll-lock checks. No public website deployment has been performed.

## Local refinement (v0.5)

`src/brand-content.json` is the shared source for the catchphrase and supplied custom font assets. `scripts/resources.py` and `scripts/icons.mjs` read the same source for material generation. Brand foundations now owns visual identity decisions, linked to dedicated pages; Voice owns writing guidance. Logo specimens use the unchanged mascot and live Mojo Draft wordmark; light background choices avoid inventing a reversed variant. Size demos and earlier measurements are explicitly unapproved.

The hero has no decorative cat. Hard stepped clipping and square details replace the CSS blend, with stationary scenery and a small stepped steam animation. Pause or reduced motion freezes it. Display punctuation is wrapped by `accentHeadings` with attached word/period spans; forest is used on cream and sage on forest. Ordinary body text, code, filenames and editable specimens are unaffected. Colour contrast labels are calculated from computed styles of each rendered pairing. Interface warning and error examples remain proposed functional values.

Run `python3 scripts/resources.py` to copy the exact custom fonts and regenerate the ZIP; run `node scripts/icons.mjs` with the dev server to regenerate icons and preview metadata. Custom font source licence/readme files and separate WOFF/WOFF2 sources are missing. All actual supplied TTF files are included. This revision is available in the GitHub source repository. The website has not been publicly deployed.
